# Chimneystar – פורטל סוכני מכירות

הכתובת היא `https://thechimneys.vercel.app/studio`. הפורטל לא מקושר מהאתר ולא מופיע בגוגל.

## כניסה (כרגע: פתוח)

כרגע אין מסך כניסה. הפורטל נפתח כאילו עובד כבר מחובר, והעובד הוא הרשומה הראשונה בטבלת `employees`, שנוצרת לבד.
**שימו לב:** כל מי שמגיע לכתובת רואה את הלקוחות וההזמנות האמיתיים ויכול להפעיל את הוויזואליזציה על חשבון Google.

כשיהיה אתר מנהל (פתיחת עובד, שם משתמש וסיסמה):
1. ב-`api/_auth.js` משנים את `OPEN_ACCESS` ל-`false`.
2. הפונקציה `currentEmployee()` צריכה לקרוא את העובד מעוגיית ההתחברות.

הטבלה `employees` כבר מוכנה לזה: יש בה שם משתמש, `password_hash`, שם, תפקיד, טלפון, אימייל ושדה פעיל.

## מה יש בפורטל

- **פתיחת לקוח חדש**
- **לידים ממתינים:** כל ליד שנשאר מטופס האתר (`lead.html`) מגיע לכאן אוטומטית.
- **לקוחות לחזור אליהם:** לפי תאריך ושעה, כשמה שעבר זמנו מסומן באדום ומה שצריך לטפל בו היום בכתום.
- **פתיחת הזמנה חדשה:** פתיחת הזמנה הופכת את הליד ללקוח.
- **ויזואליזציה:** מצלמים את הבית ומקבלים לפני/אחרי עם ארובה חדשה.
- **הגדרות ופרטים אישיים:** הפרופיל של העובד המחובר (שם, טלפון, אימייל) נשמר במסד הנתונים. השם מופיע על כל לקוח, הזמנה והערה.

בכרטיס הלקוח יש כפתורים להתקשר, לשלוח וואטסאפ ולערוך, לקבוע מתי לחזור ללקוח, לסמן "לקוח" או "לא רלוונטי", לפתוח הזמנות ולתעד שיחות.

## הגדרה ב-Vercel (פעם אחת)

Project → Settings → Environment Variables:
- `GEMINI_API_KEY`: המפתח של Google, בשביל הוויזואליזציה

**מסד הנתונים (Neon Postgres):** Project → Storage → Create Database (או Marketplace) → **Neon** → Create, ואז Connect לפרויקט.
Vercel מוסיף לבד את `DATABASE_URL`, והטבלאות נוצרות לבד בשימוש הראשון. אחרי החיבור עושים Redeploy.

עד שמסד הנתונים מחובר, טופס הלידים באתר ממשיך לעבוד כמו קודם ופותח מייל, כך שאף ליד לא הולך לאיבוד.

## קבצים

- `studio/index.html`: כל המסכים
- `studio/core.js`: כניסה, ניווט, כלים משותפים
- `studio/crm.js`: לקוחות, לידים, הזמנות, הגדרות
- `studio/visualizer.js`: הוויזואליזציה
- `api/crm.js`: ה-API של הלקוחות וההזמנות
- `api/lead.js`: קליטת לידים מהאתר
- `api/studio.js`: יצירת התמונות
- `api/_db.js`: מסד הנתונים
- `api/_auth.js`: מי העובד המחובר. כאן מחליפים את הגישה הפתוחה בכניסה אישית.

## קטלוג ארובות

1. שמים בתיקייה `studio/chimneys/` תמונות של כל ארובה. הכי טוב 2–4 זוויות על רקע נקי.
2. מוסיפים רשומה לקובץ `studio/chimneys/catalog.js`. הארובות מופיעות גם בוויזואליזציה וגם כהצעות בשדה "מוצר" בהזמנה.
