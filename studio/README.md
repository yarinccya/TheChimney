# סטודיו הדמיות ארובה (פרטי)

כלי פרטי שמקבל תמונה של בית לקוח ומחזיר הדמיה ריאליסטית של הבית עם ארובה מהקטלוג שלך.
הכתובת: `https://thechimneys.vercel.app/studio`. הכלי לא מקושר מהאתר, לא מופיע בגוגל (noindex), ומוגן בסיסמה.

## הגדרה חד-פעמית

1. **מפתח Gemini:** נכנסים ל-https://aistudio.google.com/apikey, יוצרים מפתח API ומחברים חשבון חיוב (Billing).
   המודל Nano Banana Pro בתשלום בלבד: בערך 0.13–0.15 דולר לתמונה ב-2K, ובערך 0.24 דולר ב-4K.
2. **ב-Vercel:** Project → Settings → Environment Variables. מוסיפים:
   - `STUDIO_PASSWORD`: הסיסמה שלך לכלי
   - `GEMINI_API_KEY`: המפתח משלב 1
   - `GEMINI_MODEL` (לא חובה): ברירת המחדל היא `gemini-3-pro-image`
3. עושים Redeploy, או פשוט דוחפים את הקוד.

> המאגר ב-GitHub ציבורי, ולכן אסור לשים את המפתח או את הסיסמה בקוד. הם נשמרים רק ב-Vercel.

## הוספת ארובות לקטלוג

1. שמים בתיקייה `studio/chimneys/` תמונות של כל ארובה. הכי טוב 2–4 זוויות (חזית, צד, תקריב של הכובע) על רקע נקי.
2. מוסיפים רשומה לקובץ `studio/chimneys/catalog.js` עם שם, תיאור באנגלית ורשימת התמונות.

## טיפים לדיוק מקסימלי

- צלמו באור יום, מזווית שבה רואים את הגג בבירור, ובלי זום דיגיטלי.
- סמנו את כל הגובה שהארובה תתפוס מעל הגג, ולא רק את הבסיס. במצב "החלפה" סמנו את כל הארובה הישנה.
- תיאור מדויק (חומר, צבע, קוטר, סוג כובע) ועוד זוויות של המוצר משפרים את ההתאמה.
- כדאי ליצור 2–3 גרסאות ולבחור את הטובה ביותר.
- המתג "שמור את כל שאר התמונה מקורית" מחזיר כל פיקסל מחוץ לאזור המסומן למקור. אם הארובה נחתכת בקצה, הגדילו את הסימון או כבו את המתג.
